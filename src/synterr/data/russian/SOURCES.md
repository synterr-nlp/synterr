# Источники данных для русского языка

## Паронимы (`paronyms.json`)

Словарь паронимов объединяет данные из нескольких источников:

### 1. Словарь паронимов ЕГЭ

**Источник:** Материалы Единого государственного экзамена по русскому языку

Паронимы, используемые в заданиях ЕГЭ (задание 5). Включают наиболее частотные пары паронимов, которые путают носители языка и изучающие русский как иностранный.

**URL:** https://rus-ege.sdamgia.ru/

### 2. О.В. Вишнякова. Словарь паронимов русского языка

**Библиографическая ссылка:**
> Вишнякова О.В. Словарь паронимов русского языка. — М.: Русский язык, 1984. — 352 с.

Академический словарь, содержащий около 1000 паронимических рядов. Включает:
- Паронимы-прилагательные (наибольшая группа)
- Паронимы-глаголы
- Паронимы-существительные
- Паронимы-наречия

### 3. Claude AI generated

**Модель:** Claude Sonnet (Anthropic)
**Дата генерации:** январь 2025

Паронимы, сгенерированные с помощью языковой модели на основе:
- Анализа ошибок в корпусе RULEC-GEC
- Лингвистических закономерностей русского языка
- Типичных ошибок изучающих русский язык

**Категории генерации:**
- Классические паронимы (надеть/одеть)
- Прилагательные на -ический/-ичный
- Глаголы с приставками
- Паронимы по модели словообразования

## Формат данных

```json
{
  "_meta": {
    "description": "...",
    "sources": {...}
  },
  "слово1": ["ошибка1", "ошибка2"],
  "слово2": ["ошибка1"]
}
```

- Ключ — правильное слово
- Значение — массив слов, которыми его часто ошибочно заменяют
